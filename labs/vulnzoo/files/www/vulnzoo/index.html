Description

VulnZoo is a cybersecurity training platform that simulates vulnerable devices from multiple domains, inspired by OWASP projects such as IoTGoat. It covers automotive, IoT, medical, and network devices, so users can explore real-world vulnerabilities in current systems.

01Realistic environments

Runs on OpenWRT, the Linux-based firmware for embedded devices, with a web service that manages each vulnerable lab. Multiple simulated devices coexist in a single image.

02OWASP-aligned labs

Each lab includes typical vulnerabilities identified by OWASP, adapted to the device category — covering both exploitation and mitigation so you can practice both sides of the fence.

03Complex scenarios

Labs integrate cloud APIs, mobile apps, and interconnected devices, replicating the full attack surface of real-world products rather than isolated firmware snippets.

04Secure-mode toggle

Each lab ships with a hardened configuration you can switch to, letting you compare vulnerable vs. protected setups and internalize the concrete mitigations.
