VulnZoo

Description

VulnZoo is a cybersecurity training platform that simulates vulnerable devices from different fields, inspired by OWASP projects such as IoTGoat. The environment covers automotive, IoT, medical, network, and more devices, allowing users to explore and learn about real-world vulnerabilities in current systems. The simulator runs on OpenWRT, a Linux-based firmware for embedded devices, and integrates a web service from which the features of each vulnerable device are managed. One of VulnZoo's main advantages is the ability to integrate multiple simulated devices into a single image, ensuring the compatibility and flexibility offered by OpenWRT. The goal of VulnZoo is to provide a complete and realistic environment for product cybersecurity training and certification. Each lab includes typical vulnerabilities identified by OWASP, adapted to each type of device, allowing users to experience and learn both about exploitation and mitigation of security flaws. To increase realism, some labs include several components, such as cloud APIs, mobile services, and interconnected devices, replicating complex and current scenarios. In addition, the source code is available so users can compile custom images, facilitating deployment on different architectures and promoting deep learning about configuration and security. Each lab offers the option to apply secure configurations, allowing users to compare the vulnerable environment with a protected one and learn best practices to mitigate risks.
