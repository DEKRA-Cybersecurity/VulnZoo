What is this environment?

OwlCam is a simulation environment designed for security analysis in enterprise video surveillance services. The lab reproduces a private security company where each user has access to their own set of cameras through a dedicated API and a mobile application. The system includes multiple clients and an administrator with elevated privileges.

The goal of the lab is to identify and exploit vulnerabilities in authentication management, access control, and domain segregation. If the service is successfully compromised, it is possible to access data and cameras outside the user's legitimate domain — demonstrating exposure of sensitive information, privilege escalation, and unauthorized access.

Practice pentesting on APIs and mobile applications, analyze the architecture of video surveillance services, and understand the most relevant attack vectors in these environments.
