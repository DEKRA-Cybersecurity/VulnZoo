What is this environment?

This section of the VulnZoo project provides a vulnerable environment that simulates the operation of an OpenWRT-based router. When loaded, RoutCoon exposes its native LuCI administrative interface with intentional vulnerabilities for security testing and learning.

VulnZoo WWW interface — device management, loading/stopping devices, and project administration.

RoutCoon LuCI interface — the actual vulnerable router administrative interface (available at port 4343 when RoutCoon is loaded). This is where you perform penetration testing.

Inspired by the OWASP Internet of Things project, allowing users to experiment and practice pentesting techniques on IoT devices safely.
