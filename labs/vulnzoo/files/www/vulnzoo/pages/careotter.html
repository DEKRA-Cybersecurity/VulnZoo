What is this environment?

CareOtter is a vulnerable IoT healthcare device simulator designed for security testing and learning. This lab reproduces a modern cardiac implantable electronic device similar to a ICD (Implantable Cardioverter-Defibrillator) — a sophisticated computer that manages autonomous heart rhythm control.

Modern DAIs have evolved from simple "arrhythmia extinguishers" into sophisticated cardiac computers that manage life-or-death situations in milliseconds. Like a small pacemaker, they maintain the heart at a marked rhythm when it weakens, but they can also deliver an electric shock when a critical arrhythmia is detected.

When a DAI releases an electric shock (defibrillation), a series of automatic actions and medical protocols are triggered, since a discharge is considered a critical event. The CareOtter simulator models this complex medical environment with realistic telemetry, cloud synchronization, and mobile monitoring — allowing security researchers to understand the real-world impact of vulnerabilities in life-critical medical IoT devices.

VulnZoo WWW Interface: Used for device management, loading/stopping the CareOtter simulator, and project administration.

CareOtter Device Interface: The actual vulnerable IoT device with BLE services, web panel, and API endpoints — this is where you perform penetration testing on medical IoT vulnerabilities.

Device Architecture

The CareOtter lab comprises multiple interconnected components that mirror a real-world connected medical device ecosystem:

  • BLE Communication: The device exposes Bluetooth Low Energy GATT services for continuous heart rate and SpO₂ monitoring, allowing direct interaction with mobile health applications and wearable controllers.
  • Cloud API: A backend gateway bridges the binary device protocol to HTTP REST APIs, enabling remote patient monitoring, clinician dashboards, and firmware configuration over the network.
  • Web Interface: An embedded dashboard provides real-time visualization of cardiac telemetry, device status, and administrative controls accessible from any browser on the local network.
  • Data Storage: The simulator maintains persistent telemetry logs and configuration data, modeling how real medical devices store sensitive patient information over time.
  • Mobile App: An Android companion application connects to the device via both BLE and the cloud API, simulating how patients and caregivers interact with modern implantable cardiac devices remotely.

Security Training Focus

CareOtter supports multiple security profiles for different training scenarios. Each phase is managed through idempotent hooks that reconfigure the device without requiring code changes.

  • Phase 1 (Secure): Baseline secure configuration with all protections enabled
  • Phase 2 (Wireless): Relaxed BLE security controls — practice wireless attack surfaces
  • Phase 3 (Network): Weakened cloud and API protections — practice network-based attacks
  • Phase 4 (Data): Reduced storage and logging protections — practice data extraction

When CareOtter is loaded, you can explore vulnerabilities across multiple attack surfaces including wireless communication protocols, cloud synchronization mechanisms, web-based management interfaces, local data persistence, and mobile application integrations.
